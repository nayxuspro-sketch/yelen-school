1 Inscriptions

Le module Inscriptions permet de gérer l'enregistrement et l'inscription des élèves.

Enregistrer un nouvel élève

  • Aller dans Inscriptions → Élèves
  • Cliquer sur "Nouvel élève"
  • Remplir les informations : nom, prénom, date de naissance, sexe, pièce d'identité
  • Enregistrer — l'élève est créé avec un matricule automatique

Inscrire un élève à une classe

  • Aller dans Inscriptions → Inscriptions
  • Sélectionner l'année scolaire et la classe cible
  • Cocher les élèves à inscrire
  • Confirmer l'inscription

Réinscription massive

  • Aller dans Inscriptions → Réinscription
  • Sélectionner la classe source et la classe cible
  • Cocher les élèves à réinscrire
  • Valider
💡 Astuce : Utilisez les filtres pour rechercher rapidement un élève par nom ou matricule.

2 Pédagogie

Ce module gère les notes, évaluations et bulletins.

Configurer les matières

  • Aller dans Pédagogie → Matières
  • Créer une matière avec son coefficient
  • Associer la matière aux classes via Enseignements

Saisir les notes

  • Aller dans Pédagogie → Saisie de notes
  • Sélectionner la classe, la matière et le type d'évaluation
  • Saisir les notes — les champs invalides sont marqués en rouge
  • Enregistrer

Générer les bulletins

  • Aller dans Pédagogie → Bulletins
  • Sélectionner la classe et le trimestre
  • Générer les bulletins PDF par élève ou par classe
⚠️ Attention : Vérifiez les appréciations dans Paramètres avant de générer les bulletins.

3 Présences

Gérez les appels quotidiens et les absences.

Faire l'appel

  • Aller dans Présences → Appels
  • Sélectionner la classe et la date
  • Marquer les élèves absents (A) ou retards (R)
  • Enregistrer

Justifier une absence

  • Aller dans Présences → Justifications
  • Cliquer sur l'absence à justifier
  • Sélectionner le motif et ajouter une remarque si nécessaire
  • Valider
💡 Les parents peuvent justifier les absences via le portail parent (si activé).

4 Examens

Planifiez les sessions d'examens et gérez les candidats.

Créer une session

  • Aller dans Examens → Sessions
  • Créer une nouvelle session avec dates et capacité
  • Définir les centres d'examen

Inscrire des candidats

  • Ouvrir la session d'examen
  • Aller dans Inscrire par classe
  • Sélectionner les élèves et le centre
  • Valider

Imprimer les listes

  • Dans la session, cliquer sur Liste candidats PDF
  • Filtrer par centre si nécessaire
  • Télécharger le PDF

5 Finances

Gérez les paiements de scolarité et suivez les encaissements.

Enregistrer un paiement

  • Aller dans Finances → Paiements
  • Sélectionner l'élève
  • Indiquer le montant et le mode de paiement
  • Un reçu PDF est généré automatiquement

Créer un échéancier

  • Aller dans Finances → Échéancier
  • Sélectionner l'élève et les rubriques
  • Définir les dates d'échéance
  • Enregistrer

Suivre les encaissements

  • Aller dans Finances → Bilan encaissements
  • Sélectionner la période
  • Visualiser les graphiques et statistiques
💡 Les reçus sont numérotés automatiquement (REC-2026-00001).

6 Personnel

Gérez les employés de l'établissement.

Ajouter un membre du personnel

  • Aller dans Personnel → Liste
  • Cliquer sur "Nouveau membre"
  • Remplir les informations : nom, prénom, poste, date d'embauche
  • Enregistrer

Désactiver un membre

  • Dans la liste, cliquer sur le bouton ⚡ (toggle)
  • Confirmer — le membre est marqué comme inactif
⚠️ Les membres désactivés n'apparaissent plus dans les listes mais leurs données sont conservées.

7 Vie scolaire

Emplois du temps, sanctions, activités parascolaires.

Créer un emploi du temps

  • Aller dans Vie scolaire → Emploi du temps
  • Sélectionner la classe
  • Ajouter les cours par créneau
  • Enregistrer

Enregistrer une sanction

  • Aller dans Vie scolaire → Sanctions
  • Sélectionner l'élève, le type et la gravité
  • Ajouter une description
  • Enregistrer

8 Documents

Générez les documents administratifs.

Générer une liste de classe

  • Aller dans Documents → Listes de classes
  • Sélectionner la classe et le format
  • Télécharger le PDF

Cartes scolaires

  • Aller dans Documents → Cartes scolaires
  • Sélectionner la classe
  • Générer les cartes pour tous les élèves

9 Paramètres

Configurez l'établissement et les règles métier.

Identité de l'établissement

  • Aller dans Paramètres → Identité établissement
  • Télécharger le logo, la signature et le cachet
  • Ces éléments apparaissent sur les PDF

Configurer les signataires

  • Aller dans Paramètres → Signataires
  • Ajouter les personnes habilitées à signer les documents
  • Définir leur fonction et ordre de signature

Cycles et Classes

  • Aller dans Paramètres → Cycles
  • Créer les cycles (Primaire, Collège, Lycée)
  • Ajouter les classes et les associer à un cycle
