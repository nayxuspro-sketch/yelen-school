01

Inscriptions

Gestion centrale du cycle de vie des élèves, de l'enregistrement au suivi scolaire annuel.

Enregistrer un nouvel élève

  • Naviguer vers Inscriptions → Élèves.
  • Cliquer sur + Nouvel élève.
  • Remplir les données d'état civil (Nom, Prénom, Date de naissance, Sexe).
  • Le système génère automatiquement un matricule unique (ex : BF-2026-00001) — non modifiable.

Inscrire un élève à une classe

  • Aller dans Inscriptions → Inscriptions.
  • Sélectionner l'année scolaire en cours et la classe cible.
  • Rechercher l'élève par matricule ou par nom.
  • Choisir le statut tarifaire (Régulier, Boursier, etc.).
  • Valider l'inscription définitive.

Astuce : Utilisez la barre de recherche pour trouver un élève par son matricule ou son nom, quel que soit le module actuel.

02

Pédagogie

Outils de suivi des performances académiques et génération des rapports trimestriels.

Saisie des évaluations

  • Accéder à Pédagogie → Saisie de notes.
  • Filtrer par Classe, Matière et Trimestre.
  • Saisir les notes sur 20. Le système valide en temps réel (rouge si hors plage).
  • Cliquer sur Enregistrer pour figer les notes.

Production des bulletins

  • Aller dans Pédagogie → Résultats → [classe].
  • Cliquer sur Bulletins PDF (batch) pour le trimestre souhaité.
  • Le système calcule automatiquement les moyennes, rangs et statistiques de classe.
  • Télécharger le PDF global ou les bulletins individuels depuis la colonne Actions.

Attention : Toute modification de note après génération d'un bulletin nécessite une nouvelle génération. Un signataire de type BULLETIN doit être configuré dans Paramètres → Signataires.

03

Présences

Contrôle de l'assiduité des élèves et communication avec les parents.

Faire l'appel

  • Aller dans Présences → Faire l'appel et sélectionner la séance.
  • Pour chaque élève, choisir parmi les 3 statuts : Présent, Absent, En retard.
  • Le bouton « Tout présent » coche tous les élèves en un clic.
  • Brouillon : sauvegarde sans clôturer (modifiable). Clôturer : archive définitivement (irréversible).
  • En cas d'absence, un SMS automatique est envoyé aux parents si le module SMS est configuré.

Justifier une absence

  • Aller dans Présences → Justifications (AVS, Censeur ou Directeur).
  • Créer une justification avec le motif et la période concernée.
  • Le Censeur ou le Directeur accepte ou refuse — si acceptée, l'absence passe de Absent à Excusé.

Pointage QR Code : Chaque élève dispose d'un QR code unique. Scanner = présence enregistrée instantanément. Disponible dans Présences → Pointage QR.

04

Examens Officiels

Organisation des sessions d'examens officiels (BAC, BEPC, CEP) et gestion des candidats.

Créer une session et inscrire les candidats

  • Aller dans Examens → + Nouvelle session et renseigner le type et les dates.
  • Configurer les centres et salles via Examens → Centres.
  • Inscrire les candidats depuis Examens → Candidats → + Inscrire.
  • Saisir les résultats puis générer la liste officielle par centre.
05

Finances

Comptabilité scolaire : encaissements, arriérés, bourses et bilans financiers.

Enregistrer un paiement

  • Aller dans Finances → + Nouveau paiement ou depuis le profil élève (icône $).
  • Rechercher l'élève — sa situation financière s'affiche immédiatement.
  • Les rubriques apparaissent en cartes cliquables : soldées (grisées) ou en attente.
  • Cliquer sur une carte pour la sélectionner et saisir le montant versé.
  • Le bouton ⚡ Tout régler sélectionne toutes les rubriques en attente en un clic.

Bourses et exonérations

  • Finances → Types de bourses → + Nouveau type : configurer la réduction (% ou FCFA fixe).
  • Finances → Bourses → + Attribuer : associer la bourse à un élève — le montant dû est réduit automatiquement.
  • Finances → Élèves exonérés : exempter totalement un élève d'une rubrique.

Relances de paiement

  • Aller dans Finances → Relances.
  • Sélectionner l'année, la classe, la rubrique et la date limite.
  • Le nombre d'élèves redevables s'affiche automatiquement.
  • Générer le PDF (coupons A5, 3 par page) ou envoyer les SMS de relance.

Tous les montants sont enregistrés en FCFA conformément aux normes de l'UEMOA.

06

Ressources Humaines

Gestion du personnel permanent et des vacataires : dossiers, contrats, salaires et congés.

Dossiers du personnel

  • Aller dans Personnel → + Nouveau membre.
  • Renseigner l'identité, la fonction et les cycles d'enseignement.
  • Le matricule PERS-AAAA-NNNNN est généré automatiquement.

Vacations et salaires

  • Personnel → Vacations → + Nouveau contrat : créer un contrat vacataire, saisir les heures effectuées, générer le bulletin de vacation PDF.
  • Personnel → Salaires : saisir les éléments de paie mensuels.
  • Personnel → Congés → + Nouvelle demande : gérer les demandes de congé.
07

Vie Scolaire

Suivi disciplinaire, activités parascolaires et capital de points des élèves.

Sanctions et discipline

  • Aller dans Vie scolaire → Sanctions → + Nouvelle sanction.
  • Renseigner l'élève, le type (Avertissement, Blâme, Exclusion…), la date et le motif.
  • Les sanctions déduisent des points du capital de l'élève — alerte si le capital tombe à 0.

Activités parascolaires

  • Créer des activités dans Vie scolaire → Activités.
  • Inscrire les participants depuis la fiche de l'activité.
08

Documents Administratifs

Génération de documents officiels signés : certificats, attestations, convocations, circulaires.

Documents disponibles

  • Certificat de scolarité — Documents → Certificat → saisir le matricule → Générer.
  • Attestation de fréquentation — Documents → Attestation de fréquentation.
  • Relevé de notes / Cursus scolaire — Documents → Cursus scolaire.
  • Autorisation d'absence — Documents → Autorisation d'absence.
  • Liste alphabétique d'une classe — Documents → Listes de classe.
  • Convocations — Documents → Convocations → + Nouvelle convocation.
  • Circulaires — Documents → Circulaires → + Nouvelle circulaire.

Chaque type de document requiert un signataire configuré. Aller dans Paramètres → Signataires des documents pour les créer (type, cycle, membre du personnel).

09

Paramètres

Personnalisation de YELEN SCHOOL : identité de l'établissement, années scolaires, SMS et comptes.

Identité de l'établissement

  • Uploader le logo et le tampon dans Paramètres → Établissement → Identité.
  • Configurer les signataires autorisés par cycle et par type de document.
  • Les signatures scannées apparaissent automatiquement sur les PDF officiels.

Années scolaires et trimestres

  • Paramètres → Années scolaires → + Nouvelle année : créer et activer l'année courante.
  • Paramètres → Trimestres : créer les 3 périodes avec leurs dates.
  • Finances → Rubriques puis Finances → Tarifs : définir les frais par classe.

Configuration SMS

  • Aller dans Paramètres → Configuration SMS.
  • Renseigner le fournisseur (Semaphore, Twilio…), la clé API et le nom de l'expéditeur.
  • Utiliser le bouton Envoyer un SMS test pour valider la configuration.

Comptes utilisateurs

  • Administration → Utilisateurs → Nouvel utilisateur : créer un compte avec son rôle.
  • Rôles disponibles : DIRECTEUR · PROVISEUR · CENSEUR · SECRÉTAIRE · COMPTABLE · ENSEIGNANT · PARENT.
  • Nouveau compte parent : associe les élèves liés pour les notifications et le portail parent.

L'assistant IA intégré (Administration → Assistant IA) répond aux questions sur les données en temps réel et aux questions de fonctionnement grâce à la base de connaissances du guide.
